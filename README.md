# Dutch bucket system: quantity planning worksheet

Use this worksheet to turn a plant count into a parts list for a Dutch bucket (bato bucket) system before you request a quotation. It reflects the questions BLUSTAL, a Ludhiana manufacturer of hydroponic equipment, receives from tomato, cucumber and capsicum growers.

## Worksheet

| Step | What to write down |
|---|---|
| 1 | Crop and plants per square metre you plan to grow |
| 2 | Usable bed area in the polyhouse (length x width, minus walkways) |
| 3 | Buckets = plants needed (one plant per bucket is the usual start) |
| 4 | Growing media per bucket (volume in litres) and total for the whole house |
| 5 | Drain line length and slope back to the reservoir |
| 6 | Reservoir volume and the pump flow needed to feed the full line |
| 7 | Drip emitters, feeder lines and connectors per bucket |

## Common mistakes

- Ordering buckets without allowing for the media volume. Media is often the biggest bulk item.
- Draining into a line with no slope, so water stands in the buckets.
- Sizing the reservoir for one irrigation event instead of the whole daily cycle.
